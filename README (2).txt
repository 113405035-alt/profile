陳怡薰｜個人介紹與學習歷程網站
============================

一、檔案說明
- index.html：網站文字、段落、連結與頁面結構
- style.css：米白 × 鼠尾草綠配色、版面、手機排版與動畫
- script.js：手機選單、捲動動畫、年份更新、個人照片切換
- README.txt：本說明文件

二、預覽方式
1. 解壓縮整個 ZIP 檔案。
2. 請將 index.html、style.css、script.js 放在同一個資料夾。
3. 用瀏覽器開啟 index.html。
4. 網站使用原生 HTML/CSS/JavaScript，無需額外安裝套件。

三、加入個人照片
1. 在 index.html 所在資料夾建立 images 資料夾。
2. 把照片命名為 profile.jpg，放入 images/profile.jpg。
3. 重新整理頁面，就會自動以照片取代預設的綠色裝飾圖。
4. 建議採用直式照片；如果使用其他名稱或格式，請同時修改 index.html 中 img 的 src。
5. 上傳網站時，請記得一併上傳 images 資料夾。

四、編輯文字
1. 使用 VS Code 或其他純文字編輯器開啟 index.html。
2. 搜尋「陳怡薰」可找到姓名；搜尋「學習成果」可找到預留作品卡片。
3. 作品目前為空白範例，尚未代表真實作品或經歷。請替換為個人實際內容。
4. 搜尋 113405035@g.nccu.edu.tw 可修改公開的聯絡 Email。
5. 若日後要調整顏色，請修改 style.css 開頭的 :root 色彩變數。

五、上傳網站
【GitHub Pages】
1. 登入 GitHub，建立公開 Repository。
2. 上傳 index.html、style.css、script.js（README.txt 可保留）。
3. 前往 Settings > Pages，選擇 Deploy from a branch。
4. 選擇 main 分支及 / (root)，儲存。
5. 部署完成後，從 Pages 取得網站網址。

【一般網站主機 / cPanel】
1. 將 index.html、style.css、script.js 上傳到 public_html/ 或欲使用的子資料夾。
2. 若有照片，連同 images/ 一起上傳。
3. 以你的網域連結打開即可。

六、注意
- 本網站不含後端或線上表單；Email 按鈕使用 mailto:。
- 網站未引用外部 CDN，因此除個人照片外，所有樣式及互動都包含在提供的檔案中。
- 網站內容以 2026 年提供的「政大大三、廣告與法律雙主修」資訊撰寫；日後請視實際就學狀態更新。
