個人介紹網站｜四檔案版本
====================

本版本沿用先前個人介紹網站的原始排版、配色與文案，只將 CSS、JavaScript 拆成獨立檔案。

檔案說明
- index.html：首頁內容與網站結構
- style.css：配色、排版、手機響應式樣式
- script.js：自動更新頁尾年份
- README.txt：使用與上傳說明

本機預覽
將四個檔案放在同一個資料夾，雙擊 index.html 即可在瀏覽器開啟。

網站上傳
1. 解壓縮 ZIP。
2. 保持 index.html、style.css、script.js 在同一層資料夾。
3. 上傳至 GitHub Pages 專案根目錄、Netlify，或一般網頁主機的 public_html 目錄。
4. 網頁會自動載入相同資料夾的 style.css 與 script.js。

修改個人資訊
在 index.html 中搜尋「你的名字」、「hello@example.com」及作品名稱，改成自己的資料。
如需調整配色，可修改 style.css 開頭 :root 的顏色變數。

本網站不需伺服器、資料庫或額外套件，所有版面資源均為本地檔案。
