陳怡薰｜政大廣告 × 法律個人介紹網站（重新生成版）
=================================================

【檔案】
index.html  網站內容（姓名、介紹、學習方向、作品區、Email）
style.css   米白與鼠尾草綠配色、排版、手機版樣式
script.js   手機導覽、滾動動畫、年份更新、照片顯示
README.txt  編輯與上傳說明

【本機預覽】
1. 解壓縮 ZIP，四個檔案保持在同一個資料夾。
2. 雙擊 index.html，用瀏覽器檢視。
3. 使用 VS Code 開啟資料夾，修改 index.html 文字後 Ctrl+S 儲存，再重新整理瀏覽器。

【新增個人照片】
1. 在 index.html 旁建立 images 資料夾。
2. 放入照片：images/profile.jpg
3. 重新整理網頁，照片會自動取代預留圖案。
4. 將網站上傳 GitHub 時，images 資料夾也要一起上傳。

【修改外觀】
打開 style.css，修改開頭 :root 中的顏色變數，例如 --sage、--cream。

【更新 GitHub Pages】
1. 進入原本的 GitHub Repository，不必刪除整個儲存庫。
2. 在 Code 頁面點 Add file > Upload files。
3. 上傳新版 index.html、style.css、script.js、README.txt 到原本相同目錄。
4. 若 GitHub 顯示相同檔名，請依介面更新檔案或在單一檔案編輯頁面直接覆蓋內容並提交。
5. 按 Commit changes，等待 GitHub Pages 更新，再重新整理網站。
6. 若 GitHub Pages 尚未啟用：Settings > Pages > Deploy from a branch > main > / (root)。

本網站不依賴外部 CDN，不需要後端、資料庫或安裝額外套件。
